## `__host__ __device__` 双修饰符函数

在 CUDA 编程中，`__host__ __device__` 同时修饰一个函数时，代表该函数可以且只能在两种上下文中被调用：

+ 在主机端（CPU）代码中被调用（由 `__host__` 赋予）
+ 在设备端（GPU）代码中被调用（由 `__device__` 赋予）

编译器会为该函数生成两份编译副本，一份给 CPU 用，一份给 GPU 用

限制：该函数不能使用 CUDA 内置的线程索引变量（如 `threadIdx.x`、`blockIdx.x` 等），因为这些变量仅在 GPU 端有效。如果函数体内使用了这些变量，则它不能被标记为 `__host__`，只能标记为 `__device__`

主要用于编写通用的数学工具函数、数据处理辅助函数，让同一份代码可以在 CPU 和 GPU 上复用，避免重复编写

## BFloat16/Float16 格式
+ bf16：exp 8 位，mantissa 7 位
+ fp16：exp 5 位，mantissa 10 位
+ fp32：exp 8 位，mantissa 23 位

> 可以看到，bf16 的指数位数与 fp32 相同，因此它相当于 fp32 的截断版；对于  `__bfloat162float` 这样的 bf16 转 fp32 的函数，直接在 mantissa 位补 16 个 0 即可

## `__ldg()`
`__ldg()` 可以读取全局内存到缓存中，缓解非合并访问带来的影响

从帕斯卡架构开始，如果编译器能够判断一个全局内存变量在整个核函数范围内都只可读（比如A），则会自动使用函数 `__ldg()` 读取全局内存
